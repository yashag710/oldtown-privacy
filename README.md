# Privacy Policy

**Last updated:** September 2026

This policy covers the API client named **Oldtown**, operated by an individual creator for a single personal YouTube channel ([@Oldtown-710](https://www.youtube.com/@Oldtown-710)).

## Who this applies to

This application is used by one person, for one purpose: producing and publishing videos to my own YouTube channel. It is not a public app, website, or service. No other user signs in to it, and it does not collect data from viewers of the channel or from any third party.

## What data is accessed

The application uses the YouTube Data API v3, via Google OAuth 2.0, to access **my own YouTube account only**:

- Uploading videos I have created to my own channel
- Setting the thumbnail and captions on my own videos
- Reading the status of my own uploads

No data belonging to any other Google or YouTube user is accessed, read, or stored.

## What data is stored

Video files, titles, descriptions, and related production files are stored locally, on infrastructure I own and control, solely to produce and publish my own content. Nothing is shared with, sold to, or accessed by any third party.

## Data retention and deletion

Local production files are retained only as long as needed to produce and verify each video, and are deleted or overwritten as part of normal operation. Since no third-party or viewer data is collected in the first place, there is no such data to retain or delete.

## Third-party services

The production process may use third-party tools (for example, text-to-speech or image generation services) to help create video content. These tools process only the content I provide to make my own videos — never viewer or third-party personal data — and each is governed by its own provider's terms.

## Changes to this policy

If how this application uses the YouTube API changes, this page will be updated accordingly.
